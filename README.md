# Traanscom Store — Phase 1

This is the first working frontend version of the Traanscom multi-category e-commerce store.

## Included
- Rich multi-color visual theme (orange, purple, teal, pink, blue and warm yellow accents)
- Responsive homepage
- Categories
- Product catalog
- Search
- Category filtering
- Product details modal
- Add to cart
- Quantity controls
- Cart total
- LocalStorage cart persistence
- Mobile navigation
- Basic checkout button placeholder

## Run
Open `index.html` in a browser.
